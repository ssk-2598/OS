CODE TRACE — Ubuntu Dashboard + C Source

OPEN THE ORIGINAL GRAPHICAL DASHBOARD:
1. Extract this ZIP file.
2. Open a terminal in the extracted folder.
3. Run: ./run_dashboard.sh
   Or double-click index.html to open it in Firefox/Chrome.

COMPILE AND RUN THE SEPARATE C TERMINAL DEMO:
  gcc -Wall -Wextra -std=c11 -o code_trace code_trace.c
  ./code_trace

IMPORTANT:
The graphical dashboard is the original HTML/CSS/JavaScript website, preserved as-is.
The C source is included as a separate native Linux terminal demo; C alone does not render the website dashboard.
