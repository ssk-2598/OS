fork()

Creates a new child process. The child receives a new PID while inheriting a copy of the parent's process context.

exec()

Replaces the current process image with another program. In the original project, the child executes /bin/echo.

waitpid()

The parent waits for its child to finish, preventing the demonstration from moving forward until the child exits.

3. Handle

The handler receives the signal number and prints a confirmation message.

Project Information

Code Trace — Inside Linux Processes & System Calls

Objective

Build an educational environment that makes core Linux process and system-call concepts easy to observe, explain and present during an Operating Systems project demonstration.

Original C modules

process_demo(), signal_demo(), file_system_calls(), show_process_info(), debugging_demo() and strace_instructions().

Technologies

HTML5 • CSS3 • JavaScript • Linux concepts • C system programming • GDB • strace

Important note

This website intentionally simulates privileged OS behavior. A regular webpage cannot safely call Linux fork(), inspect the visitor's /proc, or run strace on their computer.

Presentation flow

Start at the Dashboard → run Process Creation → demonstrate Signals → trace File System Calls → inspect /proc → step through GDB → finish with Strace. This gives you a clean story from process creation to low-level system observation.
